# Приватность и достоверность

Геолокация запрашивается только по действию пользователя. Отказ не блокирует приложение: доступны районы, выбор на карте и ручные координаты.

Backend обрабатывает координаты и текст только в рамках запроса. История, аккаунты, аналитические SDK, localStorage с запросами и координатами отсутствуют. В SQLite находятся только публичные POI. Рекомендации передаются POST, ответ имеет `Cache-Control: no-store`; штатные команды запуска отключают access log Uvicorn.

Ограничитель запросов держит в памяти короткие очереди времён, индексированные хешем клиентского IP с новым случайным ключом на запуск. Исходный IP не сохраняется. Эти данные не пишутся на диск; очередь очищается по времени при следующем обращении и полностью при перезапуске. Ограничитель предназначен для одного процесса демо, не для распределённого production.

Gemini получает нормализованные фильтры и данные выбранных объектов, но не точную стартовую координату и не сырой пользовательский текст. Набор мест всё равно может косвенно указывать на район. Политика обработки данных провайдера остаётся отдельным вопросом при публичном внедрении. Ключ API хранится на сервере в окружении и исключён из Git.

По умолчанию шрифты, карта и приложение обслуживаются локально. Дополнительная онлайн-карта включается после пояснения, что OSM получит IP и запрошенную область. Эта настройка не сохраняется после закрытия страницы. Переход на внешнюю ссылку источника — явное действие пользователя.

Данные источников считаются недоверенными. React экранирует текст; источник не исполняется как HTML. LLM не выполняет команды из описаний. Результат ограничен существующими ID и проверенным словарём занятий; численные факты вычисляются отдельно. Проверка JSON сама по себе не заявляется как проверка истинности.

Неполные расписания и удобства маркируются неизвестными. Идея занятия отделена от фактов. Ночные прогулки не называются безопасными. Время перед вылетом не включает неподтверждённый трансфер в аэропорт. Приложение не предлагает проникновение на закрытые объекты.

Для публичного хостинга дополнительно проверьте журналы платформы и proxy, HTTPS и сроки хранения. Отсутствие хранения в приложении само по себе не описывает политику внешней инфраструктуры.
