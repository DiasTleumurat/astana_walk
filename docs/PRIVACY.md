# Приватность и достоверность

Единственная сохраняемая в браузере настройка интерфейса — светлая/тёмная тема (`astana-walk-theme` в localStorage). Она не содержит запросов, координат или истории посещённых мест. Без сохранённого выбора используется цветовая схема устройства.

При заданном `TWOGIS_API_KEY` приоритетный источник поиска — 2ГИС Places API. Сервер передаёт 2ГИС выбранные координаты, радиус, поисковый текст или распознанный тип/название. В запросах на сервер 2ГИС ключ находится в query-параметре по протоколу провайдера; эти URL и исходные тексты ошибок не публикуются и не журналируются приложением. В браузер ключ не передаётся. Результаты находятся только в памяти, не смешиваются с OSM и ссылаются на карточки 2ГИС. При сбое возвращается явно обозначенный сохранённый каталог OSM. Данные 2ГИС не объявляются лицензированными ODbL; подпись OSM относится к базовой карте и отдельному резервному каталогу.

Если задан `OSRMROUTE_API_KEY`, при отправке поиска сервер передаёт OSRMRoute точную выбранную координату, радиус и категории мест. Текст пожелания в Places API не передаётся. Ключ остаётся на сервере и отправляется в заголовке Authorization. Ответы с объектами обрабатываются в памяти, не сохраняются в историю. При ошибках внешнего сервиса его исходный текст не возвращается пользователю: показывается безопасное объяснение без ключей и параметров запроса.

Геолокация запрашивается только по действию пользователя. Отказ не блокирует приложение: доступны районы, выбор на карте и ручные координаты.

Backend обрабатывает координаты и текст только в рамках запроса. История, аккаунты, аналитические SDK, localStorage с запросами и координатами отсутствуют. В SQLite находятся только публичные POI. Рекомендации передаются POST, ответ имеет `Cache-Control: no-store`; штатные команды запуска отключают access log Uvicorn.

Ограничитель запросов держит в памяти короткие очереди времён, индексированные хешем клиентского IP с новым случайным ключом на запуск. Исходный IP не сохраняется. Эти данные не пишутся на диск; очередь очищается по времени при следующем обращении и полностью при перезапуске. Ограничитель предназначен для одного процесса демо, не для распределённого production.

При явной отправке формы Gemini получает текст пожелания, нормализованные фильтры и данные выбранных объектов. Точная стартовая координата отдельно не передаётся, но пользователь может сам указать адрес в тексте; набор мест также может косвенно указывать на район. Под полем есть уведомление о передаче текста Google. Первичная загрузка примера не вызывает Gemini. Политика обработки данных провайдера остаётся отдельным вопросом при публичном внедрении. Ключ API хранится на сервере в окружении или `.env` и исключён из Git.

Шрифты, обзорная карта и приложение обслуживаются локально. При отправке формы онлайн-поиск запрашивает Overpass: провайдер получает IP сервера, область Астаны и выбранные типы мест; точная стартовая координата и сырой текст пожелания не отправляются этому провайдеру. Свежие результаты обрабатываются в памяти, не записываются в SQLite или историю. Времена и статусы сбоев источника могут попадать в технический журнал без запросов и координат посетителя. Подробная онлайн-карта OpenStreetMap включена по умолчанию: сервер тайлов получает IP посетителя и область просмотра. В панели «Слой карты» можно переключиться на локальную обзорную карту. Настройка не сохраняется после закрытия страницы. Тайлы загружаются обычным браузером только для просмотра карты; массовая загрузка и предзагрузка города не выполняются. Источник и авторство указаны на карте. Переход на внешнюю ссылку источника — явное действие пользователя.

Данные источников считаются недоверенными. React экранирует ответ Gemini и подписи источников; ссылки источников проходят проверку HTTPS. Карточки и численные оценки формирует backend из каталога. Свободный ответ модели показан отдельно как ответ Gemini, а не как проверенные факты карточек. В необязательном режиме Google Search требуются веб-источники и метаданные поиска, доступны ссылки на источники рядом с утверждениями. Поисковые подсказки Google из `searchEntryPoint` показаны в изолированном iframe без выполнения скриптов. Без веб-поиска явно указано, что события, цены и часы работы не проверяются сейчас.

Неполные расписания и удобства маркируются неизвестными. Идея занятия отделена от фактов. Ночные прогулки не называются безопасными. Время перед вылетом не включает неподтверждённый трансфер в аэропорт. Приложение не предлагает проникновение на закрытые объекты.

Для публичного хостинга дополнительно проверьте журналы платформы и proxy, HTTPS и сроки хранения. Отсутствие хранения в приложении само по себе не описывает политику внешней инфраструктуры.
