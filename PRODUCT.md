# Astana Walk

## Platform
Responsive web application for residents, tourists and parents walking in Astana.

## Stack
User-approved specification: React/TypeScript/Vite, FastAPI, SQLite, multilingual embeddings, optional Gemini, Leaflet. Motion is explicitly requested. Repository was empty.

## Job
Choose one to three nearby places for the available time. User controls start point, preferences and strict filters. Facts have sources; suggested activities and estimated times are labeled.

## Evidence and constraints
Automated POI collection is mandatory. OpenStreetMap records are source data, never invented venues. Unknown opening hours and amenities remain unknown. No stored user locations or queries. No account required. A snapshot demo must work without an LLM key. Russian first; other languages are stretch goals.

## Success
A demonstrable end-to-end recommendation flow, mobile usability, source attribution, tests, reproducible ingestion and commits pushed to the supplied GitHub repository.

## Authority
The user approved the detailed technical specification in chat and delegated implementation and design using Taste Skill, Impeccable and Motion. Routine visual choices are delegated. Public hosting is not specified; deliver a running local demo and deployment-ready source.
